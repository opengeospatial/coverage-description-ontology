This is the open repository for work done within the OGC Testbed series in relation to development of a Coverage Description Ontology.

## Coverage Description Ontology

The work presented in this repository began with OGC Testbed-21, with a specific focus on developing an ontology that could be used to describe coverages represented in still and motion imagery. The ontology work in OGC Testbed-21 was conducted to support the GEOINT Imagery Media for ISR (GIMI) specification. However, it is envisaged that this repository will support similar activities in future Testbeds.
